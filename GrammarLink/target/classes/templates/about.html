📋 Project Overview

GrammarLink is a web-based educational tool that validates whether a given string belongs to a Context-Free Language using two independent formal methods: the CYK parsing algorithm (via Chomsky Normal Form) and a Pushdown Automaton simulation (stack-based state transitions).

Both methods independently accept or reject the input, visually demonstrating and proving the CFG–PDA Equivalence Theorem — the foundational result that Context-Free Grammars and Pushdown Automata recognize exactly the same class of languages.

🔬 Algorithm Pipeline

Step 1 — Grammar Parsing

Parse raw CFG text into formal model G = (V, Σ, P, S). Validates syntax, identifies non-terminals, terminals, and start symbol.

Step 2 — CNF Conversion (5 Sub-steps)

2a. New start symbol S₀ → S
2b. Eliminate ε-productions (find nullable variables)
2c. Eliminate unit productions (A → B chains)
2d. Eliminate useless symbols (non-generating / unreachable)
2e. Convert to binary form (A → BC or A → a)

Step 3 — CYK Parsing

O(n³|G|) dynamic programming. Fill triangular table T[i][j] = non-terminals deriving w[i..j]. Accept iff start symbol ∈ T[1][n].

Step 4 — PDA Simulation

Construct PDA from original CFG via standard construction. Simulate DFS backtracking over stack transitions. Record full step-by-step trace.

Step 5 — Equivalence Verification

Compare CYK and PDA results. They must agree (CFG–PDA Equivalence Theorem). Detect ambiguity by counting distinct parse trees.
