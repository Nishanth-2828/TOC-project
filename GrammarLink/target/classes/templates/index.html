What It Does

Complete TOC Validation Pipeline

Every module from the project specification, fully implemented.

📝

Grammar Input & Parsing

Type any CFG in standard notation (A → BC | a | ε). Validates syntax, identifies non-terminals, terminals, and start symbol automatically.

🔄

CNF Conversion

Full 5-step Chomsky Normal Form conversion: new start symbol, ε-elimination, unit production removal, useless symbol cleanup, and binarization.

📊

CYK Algorithm

O(n³) dynamic programming parser with interactive triangular table. Every cell shows which non-terminals derive each substring.

📚

PDA Simulation

Stack-based pushdown automaton simulation with full step-by-step trace showing state, stack contents, and transitions at each moment.

🌳

Parse Tree Visualization

Interactive canvas rendering of parse trees derived from CYK backtracking. Detects and displays multiple trees for ambiguous grammars.

⚡

Performance Analytics

Real-time nanosecond-precision timing comparison between CYK and PDA. Visualize algorithm efficiency side by side.
